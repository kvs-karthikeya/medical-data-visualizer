# Medical Data Visualizer

A freeCodeCamp Data Analysis with Python project.

## What it does

Visualizes medical examination data using matplotlib, seaborn, and pandas.

### Categorical Plot
Shows counts of good/bad outcomes for cholesterol, gluc, smoke, alco, active, and overweight — split by whether the patient has cardiovascular disease (cardio=0 or cardio=1).

### Heat Map
Shows correlation between all medical features after cleaning out incorrect data entries.

## How to run

```bash
pip install pandas seaborn matplotlib numpy
python main.py
```

## Dataset
medical_examination.csv — patient medical examination records.
